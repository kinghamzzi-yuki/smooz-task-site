# Smooz Task プライバシーポリシー

制定日：2026年10月16日

日野祐輝（以下「運営者」）は、Androidアプリ「Smooz Task」（以下「本アプリ」）での利用者の情報の扱いを、次のとおり定めます。

## 1. 集める情報

本アプリは、利用者の情報を運営者やほかの会社に送りません。本アプリはインターネットに接続する権限を持っておらず、入力された内容や端末の情報を外に送ることはできません。

広告、利用状況の分析、クラッシュの報告のための仕組みも組み込んでいません。

## 2. 端末の中に保存する情報

次の情報は、利用者の端末の中にだけ保存します。

- 利用者が入力したタスク（名前、期限、通知のタイミング）、プロジェクト（名前、色）、完了したタスクの履歴
- 本アプリの設定
- ホーム画面のウィジェットの表示（表示しているプロジェクトと月）

これらは、本アプリを削除すると端末から消えます。

Androidの「バックアップ」がオンになっている場合、これらの情報は、Androidの仕組みによって利用者のGoogleアカウントにバックアップされることがあります。このバックアップは利用者のアカウントの中に置かれるもので、運営者が見ることはできません。

## 3. 端末のカレンダーの予定

設定の「カレンダーの予定も表示する」をオンにし、カレンダーの読み取りを許可した場合に限り、本アプリは端末のカレンダーの予定（タイトル、日時、色）を読み取ります。

- 読み取った予定は、本アプリの「1日のカレンダー」に重ねて表示するためだけに使います
- 予定を本アプリの中に保存したり、外に送ったりはしません
- 本アプリから予定を書き込んだり、変えたりはしません
- 設定をオフにすると、読み取りをやめます。許可は、端末の設定からいつでも取り消せます

## 4. 本アプリが使う権限

| 権限 | 使う目的 |
|---|---|
| 通知 | タスクの期限が近いことを知らせるため |
| アラームとリマインダー | 通知を、決めた時刻に正確に出すため |
| 端末の起動時の実行 | 端末を再起動したあとも、通知の予約を続けるため |
| カレンダーの読み取り | 上の「3. 端末のカレンダーの予定」のため。オンにしたときだけ求めます |

## 5. ほかの会社への提供

本アプリは利用者の情報を集めないため、ほかの会社に提供することもありません。

## 6. 子どもの利用

本アプリは、子どもの情報を集めることはありません。

## 7. このポリシーの変更

このポリシーを変えるときは、このページで知らせます。
