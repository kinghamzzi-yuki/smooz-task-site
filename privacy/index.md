# Smooz Task プライバシーポリシー

制定日：2026年10月16日

日野祐輝（以下「運営者」といいます。）は、Android 向けアプリケーション「Smooz Task」（以下「本アプリ」といいます。）における利用者の情報の取扱いについて、次のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。

## 1. 利用者の情報の取得

本アプリには、運営者または第三者が利用者の情報を取得する機能はありません。本アプリはインターネットへの接続に必要な権限を持たないため、利用者が入力した内容や端末の情報が、本アプリから外部へ送信されることはありません。

また、本アプリには、広告の配信、利用状況の分析、クラッシュレポートの収集を目的とするツールを組み込んでいません。

## 2. 端末内に保存される情報

本アプリは、次の情報を利用者の端末内にのみ保存します。

- 利用者が入力したタスク（名称、期限、通知のタイミング）、プロジェクト（名称、色）および完了したタスクの履歴
- 本アプリの設定内容
- ホーム画面のウィジェットの表示内容（表示するプロジェクトおよび月）

これらの情報は、本アプリをアンインストールすると端末から削除されます。

なお、Android のバックアップ機能が有効になっている場合、これらの情報は Android の仕組みにより、利用者の Google アカウントにバックアップされることがあります。このバックアップは利用者のアカウント内に保存されるものであり、運営者が閲覧することはできません。

## 3. 端末のカレンダーの予定の利用

利用者が本アプリの設定で「カレンダーの予定も表示する」を有効にし、カレンダーへのアクセスを許可した場合に限り、本アプリは端末のカレンダーに登録された予定（タイトル、日時、色）を読み取ります。

- 読み取った予定は、本アプリの「1日のカレンダー」画面に表示する目的にのみ利用します。
- 読み取った予定を本アプリ内に保存すること、および外部へ送信することはありません。
- 本アプリが、端末のカレンダーに予定を追加、変更または削除することはありません。
- 設定を無効にすると、予定の読み取りを停止します。カレンダーへのアクセスの許可は、端末の設定からいつでも取り消すことができます。

## 4. 本アプリが使用する権限

| 権限 | 利用目的 |
|---|---|
| 通知 | タスクの期限が近づいたことをお知らせするため |
| アラームと<wbr>リマインダー | 指定した時刻に正確に通知するため |
| 端末の起動時の<wbr>実行 | 端末を再起動した後も、通知の予約を維持するため |
| カレンダーの<wbr>読み取り | 第3項に定める目的のため。利用者が設定を有効にした場合にのみ、許可を求めます |

## 5. 第三者への提供

本アプリは利用者の情報を取得しないため、利用者の情報を第三者に提供することはありません。

## 6. 本ポリシーの変更

運営者は、必要に応じて本ポリシーを変更することがあります。変更した場合は、本ページにおいて、変更後の内容と改定日をお知らせします。
